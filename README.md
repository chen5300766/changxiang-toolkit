## ⚠️ 关于杀毒软件误报说明

本软件为个人开发的系统工具，使用Python编写，无任何恶意代码。

**已知误报情况：**
- 360安全卫士：可能误报为木马/风险程序
- 其他杀毒软件：可能提示未知程序

**原因：**
- 个人软件无数字签名，杀毒软件对未签名的打包程序比较敏感
- 软件涉及系统清理、注册表操作等功能，容易触发启发式扫描
- 代码完全开源，可自行审查

**解决办法：**
1. 将软件目录加入杀毒软件信任区
2. 在360提示时选择"信任此程序"
3. 本软件不联网、不上传个人数据，请放心使用

如有疑问可查看源码或提交Issue。# 畅享电脑工具箱

一款轻量的Windows系统维护工具，绿色免费，无需安装。

## 功能

- **深度清理**：系统垃圾、浏览器缓存、视频/音乐软件缓存、卸载残留
- **一键清理**：快速清理临时文件、缩略图、日志
- **系统修复**：系统组件修复、网络修复、hosts重置、文件关联修复
- **软件管理**：彻底卸载软件、扫描残留文件夹
- **磁盘优化**：碎片整理、大文件查找
- **系统信息**：硬件信息、网络端口、安全状态检测
- **操作记录**：自动记录所有操作，方便回溯

## 使用方法

1. 下载zip压缩包
2. 解压到任意文件夹
3. 双击「畅享电脑工具箱.exe」运行
4. 首次运行会请求管理员权限，点"是"即可

## 系统要求

- Windows 10 / Windows 11（64位）
- 需要管理员权限

## 说明

- 绿色软件，不写注册表，不弹广告
- 操作记录保存在 %APPDATA%畅享工具箱- 自动更新功能已内置
