# 畅享电脑工具箱 🧰


一款免费的 Windows 系统优化工具，界面简洁，操作简单，适合新手使用。


## 功能介绍


- 🧹 清理优化：一键清理垃圾、软件缓存、C盘深度清理、重复文件查找、软件残留清理
- ⚙️ 系统维护：系统文件修复、网络修复、hosts检查、DirectX修复、桌面图标修复、浏览器医生
- 🛡 安全防护：防火墙一键开关、程序联网规则管理、系统安全检查
- 📦 软件管理：智能卸载软件（识别火绒/360/腾讯管家等杀毒软件）、默认程序设置
- 💾 U盘工具：U盘信息查看、错误检测、安全弹出
- ⭐ 终极功能：全面体检报告、一键智能维护
- 📜 操作记录：所有操作可追溯
